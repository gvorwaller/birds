## MANDATORY: Repository Development Guide

Before diagnosing, editing, testing, reviewing, committing, or deploying, read
`cs.md` and `docs/agent-development-guide.md` completely. The guide is the
canonical cross-agent workflow for scope control, test-data safety, UI/UX,
testing evidence, and release gates. `cs.md` remains authoritative for project
hard rules.

You must run td usage --new-session at conversation start (or after /clear) to see current work.
