## Home: pick the search area on a map (td-8e21b8)

- Home > Search area has **📍 Pick on map** beside "View a different area". It opens the shared `MapPicker` in a section after the GET form, because MapPicker has its own search `<form>` and forms can't nest. **Search near …** writes the picked label into the place box, adds hidden `lat`/`lng`/`pin` fields and submits the same form, so the current Within/Window apply. The button renders only after hydration.
- Loader: `parsePlacePin` (`src/lib/pin-params.ts`) uses the exact point only while `place` equals the `pin` label. Editing the place text, with or without JS or on a shared link, geocodes the text as before. A pin skips `geocodePlace`, so a reverse-geocoded name is never re-geocoded to a different spot. `lat`/`lng`/`pin` are read via `searchParams.get`, so `?loc=` and `?list=` remain untracked.

  - P3: parsePin's 120-character cap shortened long picked names. The pin label is now the place text, kept whole.
