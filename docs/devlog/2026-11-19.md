### Key Technical Insight

- External loads aren't jobs: the Admin Jobs card lists only the app's worker queue. Loads show under Sources → Loads and in the header job chip.
- `pkill -f <pattern>` over ssh kills the ssh shell itself when the pattern appears in its own command line; kill by PID.
