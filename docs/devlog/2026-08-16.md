### Key Technical Insight
Cancellation correctness needed FOUR review rounds to pin: it is only safe
when honored inside the terminal transition's own UPDATE (CASE WHEN
cancel_requested) — any SELECT-then-write or two-statement shape loses a
cancel that serializes between observation and write. Same lesson applied to
reclaim and requestCancel. READ COMMITTED's EvalPlanQual re-check is what
makes the blocked-UPDATE-re-evaluates pattern sound.
