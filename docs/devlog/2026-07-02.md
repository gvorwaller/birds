# 2026-07-02

## Trip Field Tip Refresh

### Summary
Fixed `td-1f2aa8`: Birds trip field-tip refresh now regenerates tips for every
current stop on the selected trip instead of reusing older persisted tips and
only filling newly added stops.

### What Changed
- Changed the trip `field_tips` action to send all current trip stops to the AI
  generator, including stops that already have saved field tips.
- Kept persistence intact: refreshed tips overwrite each stop's saved
  `field_tip` and update `field_tip_generated_at`.
- Added validation so the refresh fails visibly if the AI response omits any
  requested stop, rather than silently leaving stale tips in place.
- Updated the trip page button copy to `Refresh field tips`.
- Added unit coverage for the refresh helper to ensure all stops are selected
  for generation.
