## Home: All / Need / Seen lens (td-ee2b56)

- Home's needs card now has the Field Guide's All / Need / Seen pills. Need stays the default, so bare Home is unchanged (SSR before/after: identical rows and card text apart from the pills). The choice lives in `?list=all|seen`; invalid values self-heal to Need.
- `buildView` now also returns `seenRecent`, the already-seen part of the same area feed that the needs filter used to discard. No extra eBird calls. Seen rows are never enriched, so they show the latest report only; All/Seen sort by Latest report or Nearest.
- The loader never reads `list` (guarded in `home-loader-url-tracking.test.ts`), so switching lens is a client navigation that reuses loaded data: 0 `__data.json` requests on a switch or a hover.
- Need search keeps its original place index; All/Seen use one that also carries seen species, with a fallback so a seen-only place stays focused across a lens switch. New dark-slate "seen" map pin and legend entry.
