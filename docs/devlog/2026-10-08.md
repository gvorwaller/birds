### Key Technical Insight
- **`use:enhance` ignores parameter changes.** Read the submitted value from `formData` in the submit callback, never from a closure captured at mount.
- **`update()` / `applyAction` on success moves focus to `<body>`.** For a keyboard-driven control (check box), call `invalidateAll()` directly.
- **A NULL inside BETWEEN makes a CHECK pass.** An all-or-nothing CHECK needs explicit `IS NOT NULL`s.
- **Flex items default to `min-width: auto`.** An embedded map picker pushed its `<details>` panel past a 320px screen; set `min-width: 0` on the panel.
- **Google's Maps URL docs say 3 waypoints on mobile.** In practice the iPhone opens the Google Maps app and handled 6 fine. Owner trips are 3–4 stops a day.
- **Scope survey questions to every scenario the behavior runs in.** Here that was planning at home vs in the field. An answer about one case is not a decision about the others.
- **The prod nginx access log settles "is my phone on the new build".** Look for the hashed `_app/immutable/nodes/*.js` fetch after the PM2 restart time.
