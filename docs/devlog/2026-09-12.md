### Release smoke correction — species response headers

The first production smoke found HTTP 502 on Osprey detail while the app logged
HTTP 200. Nginx logged `upstream sent too big header`. An authenticated request
directly to the app measured 4,088 bytes of header fields (plus HTTP status line
and terminator), including 3,825 bytes of SvelteKit asset preload links. This
exceeds the platform's 4KB initial proxy response buffer. Added Birds-scoped
8KB response-header/body buffers with a compatible 16KB busy-buffer setting;
no shared global Nginx settings change. Preserve preload links and page content.
Validate the candidate with production Nginx before the standard redeploy.
Reference: https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_buffer_size
