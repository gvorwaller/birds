# 2026-08-28 — Admin worker pause control (td-729717)

- Added a persistent Admin **Pause worker / Resume worker** control. A pause
  survives worker restarts and deployments; the live worker remains healthy
  and heartbeating while paused.
- Pause is cooperative: an in-flight species/location finishes, the running
  job returns to `pending` with its attempt refunded, and no new queue item is
  claimed until Resume. Enrichment also checks the control between paid
  similar-note retries within one species.
- Added migration `0036_worker_pause.sql`, live Admin status, worker history,
  Help guidance, and a Version History note.
