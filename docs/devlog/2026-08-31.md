## What replaced what

The `region_centroids` runtime cache (~450 lines of TTLs, cooldowns, error
classification, an in-flight dedup map, plus the abandoned warm-job design) is
replaced by a seeded `regions` reference table: 252 countries + 3,369
subnational1, names + NOT-NULL coordinates + parentage, generated offline from
eBird and applied by the normal migration runner. One process-lifetime
accessor (`$server/regions`) serves pickers, labels ("Bornholm, Denmark"),
validation, and proximity coordinates — no eBird calls on any read path, no
API key needed for the pickers.

The 0045 invariant anchors every `loc_kind='region'` row to seeded geography:
country/sub1 reference themselves, counties their parent state, hotspots NULL.
Proven empirically on birds_test (FK on a STORED generated column is legal on
PG17): unseeded region → 23503; county with unseeded parent → 23503; malformed
code → shape CHECK. Prod pre-flight: 0 of 205 referenced codes missing.

The species page's Best-time-of-year card is now two peers in a tablist —
"Closest with sightings — Florida, United States · ~215 mi" vs "Best of N
loaded regions — Bornholm, Denmark" — verified rendering live. Plus: global
nav progress bar, Server-Timing/perf-line instrumentation, streamed
nearby/nearest/tide and county aggregates with reserved-height skeletons.

## Upstream discoveries (the validate-before-write gates earned their keep)

- The "[SE-01]" name suffixes come from **eBird's own region-list endpoint**,
  not the barchart export as exploration had inferred. Only Sweden's 21 are
  code-shaped (stripped); the other bracketed names are useful alternates
  ("… [Bangkok]") and kept.
- **301 codes have latitude/longitude 0,0 in eBird's own data** (XX "High
  Seas", 112 Latvian municipalities, 68 Maltese councils, …) with no bounds to
  derive from. Excluded from the seed (backend/db/regions-excluded-codes.txt,
  committed) rather than fabricating coordinates; none is prod-referenced.
- eBird's real rate ceiling is **window-based**: ~500-request initial burst,
  then bursts of ~20 between minutes of hard 429s whose `Retry-After: 3`
  header lies. Sustained ~480-500 codes/hr; the full sweep took ~8h with
  checkpointed resume. (Same documented-vs-real lesson as iNaturalist.)
