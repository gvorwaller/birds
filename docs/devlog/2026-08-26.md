## What landed (plan steps 1–7a)

1. **Migration 0034** — `app_config` (first mutable runtime config in the
   schema, no seed rows) + `ai_usage` (one row per billed-or-event ATTEMPT,
   append-only via `REVOKE UPDATE, DELETE` — 0002's default privileges make a
   bare GRANT insufficient; measured on the test cluster).
2. **`ai-models.ts`** — pure per-model request registry (thinking/effort/
   fallbacks/beta-header/max_tokens differences all encoded per entry),
   envelope extraction with the billed-vs-reported discriminator
   (`output_tokens > 0`), effective-dated pricing with family-prefix
   `served_model` matching, and `dollarsForRow` — the ONE cost formula.
3. **`app-config.ts`** — process-local last-known-good reads via `queryTimed`
   (GROK P0-1: DB-blip fallback to the compiled default would silently re-price
   a Haiku drain at Opus rates); `setConfig` validates against the registry.
4. **`ai-usage.ts`** — `recordUsage` (never throws; whole attempt chain in ONE
   INSERT with `call_id` minted in-statement — GROK P1-5) and
   `usageAggregates` (hour-bucket group pricing through `dollarsForRow`; no
   `ok`/`is_final`/distinct-call filters — each is P0-2 reborn as a SELECT).
5. **`ai-call.ts`** — `meteredAiCall` chokepoint: per-call model resolution,
   chokepoint-owned timeout signal (GROK P1-8), one recorded call on success
   and every failure shape, attempt-object return (`{result, requestedModel,
   servedModel, envelope}`).
6. **Enrichment rewire** — `generateSpeciesAnnotation(input, model,
   {fetcher, signal})` returning `{annotation, envelope}`;
   `EnrichmentAiError.envelope` on every post-response throw (the kitmur
   case: max_tokens truncation carries usage + stop_reason). job-handlers'
   three named edit sites: metered `annotate()`, keep-best swaps whole
   attempt objects, `upsertAiData` stamps the KEPT attempt's `servedModel`
   (CODEX1 P1-4). New pins: 3 retries = 3 ledger calls; fresh skip = 0 rows;
   mid-retry config change stamps the kept attempt's model.
7. **Guidance rewire** — config-resolved model, metered, shared envelope on
   `GuidanceError`; no structured outputs in v1 (deliberate).
8. **Admin server side** — loader ships registry list/current config/meter
   aggregates/data-driven quick-pick; `kind` discriminant on EVERY action
   (including the pre-existing nudge — one ActionData slot); `set_ai_model`;
   `run_compare` (parallel under a 45s per-model cap vs nginx's 60s,
   single-flight 409, abort prices to `null` never $0.00).

## Gotchas worth remembering

- `~/.claude/settings.json` blanks `ANTHROPIC_API_KEY` to `""` in Claude Code
  subprocesses, and `$env/dynamic/private` bakes its snapshot at first
  import — `??=` can't rescue an empty string. House fix (xeno-canto
  precedent): mutate the imported `env` snapshot POJO directly in tests.
- `vi.restoreAllMocks()` does not clear hoisted `vi.fn()` call history —
  `mockReset()` them explicitly or cross-test call counts accumulate.
