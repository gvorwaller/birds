### Key Technical Insight
- **A NOT over a nullable predicate drops rows from both sides.** `NOT (… AND next_retry_at > NOW() …)` is unknown when next_retry_at is NULL, so the row fell out of both "scheduled" and "waiting". Wrap the predicate in `COALESCE(…, false)`.
- **New tables inherit `birds_app=arwd`** from 0002's default privileges. A "read-only" table needs an explicit REVOKE.
- **`sudo` resets the environment.** Pass `PGCONNECT_TIMEOUT` with `sudo -u postgres env PGCONNECT_TIMEOUT=10 psql …`.
